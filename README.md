## FCWM Student Complaint Portal (PHP / XAMPP)

This project also includes a PHP and MySQL student-support portal styled with the Berry dashboard assets. It is designed to run locally under XAMPP.

### Run the portal

1. Copy the project folder into `C:\xampp\htdocs\berry` (or keep it there).
2. In the XAMPP Control Panel, start **Apache** and **MySQL**.
3. Open `http://localhost/berry/` in your browser.
4. On first launch, the application creates the `fcwm_student_support` database and its tables, then asks you to create the first administrator account. The default XAMPP connection is `127.0.0.1`, port `3306`, user `root`, with an empty password.
5. To use different database credentials, set `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD` in the PHP/Apache environment before starting Apache. The configured database user must be allowed to create the database on first launch.

The portal requires PHP 8.0 or later with PDO MySQL enabled. Do not expose a default XAMPP installation or its database to the public internet.

### Portal roles

- **Students** register with their full name, email, matric number, school, department, and password. They can submit a complaint, select a topic and a course, and follow replies using their generated reference number.
- **Administrators** review complaints, route cases to departments, create department staff accounts, and maintain the course directory.
- **Department staff** see and update only complaints assigned to their own department. They can also maintain their department's course list.

School and department choices are seeded the first time the database is initialized. Review and rename the starter entries to match the college's official structure, or add missing entries from **Schools & departments** after creating the administrator account. Add the college's course catalogue from **Course directory**.

Passwords are stored as PHP password hashes, forms use session CSRF tokens, and database writes use prepared statements. Reference numbers are randomly generated; students should keep them private.
